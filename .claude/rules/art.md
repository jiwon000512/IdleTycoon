# 아트 규칙

그림 리소스를 만들거나 고칠 때 따른다. 만드는 절차는 스킬 `asset-codex`. 옛 지상(쿼터뷰·타일·울타리) 규칙은 `기획/보관/아트-프롬프트-2026-09.md`.

## 스타일

| 항목 | 규칙 |
|---|---|
| 격자 | 월드는 **한 칸 2px · PPU 80 · 스케일 1**. 크기는 스케일이 아니라 칸 수로 정한다. 한 화면 안에서 한 칸 크기가 같아야 한다 |
| 픽셀 | 굵은 사각 픽셀, 안티에일리어싱·블러 없음. 임포트는 Point, 압축 없음 |
| 외곽선 | 서 있는 것(캐릭터·사물·소품)은 진갈색 (52,32,32) 외곽선. 검정·얇은 선은 탈락. 바닥·벽 재질에는 외곽선이 없다 |
| 색 | 채도 낮은 파스텔, 평면 5~7색. 그라데이션·디더링 없음 |
| 빛 | 한 톤 어두운 면 + 머리 위 흰 하이라이트 한 획. 바닥 그림자는 그리지 않는다(게임이 `shadow.png`를 깐다) |
| 시점 | 캐릭터는 **위 30도에서 내려다본** 모습. 앞·뒤·옆이 같은 카메라다 |
| 자세 | 손님·웜뱃·점원은 **두 발로 서서 앞발을 가슴 앞에** 든다. 옆모습도 머리와 몸이 한 덩어리인 콩 모양이고 폭·눈 높이가 앞모습과 같다 |
| 피벗 | 서 있는 것은 아래 가운데(발끝) |

## 절차

- **시안 3장 → 게임 캡처 위 비교 → 사용자 1회 선택 → 적용 1회.** 적용 전에는 프리팹을 건드리지 않는다.
- 고른 시안의 부분 수정(「여기만 다듬어」)은 다시 뽑지 않고 칸 단위로 직접 고친다.
- 원·링·막대 같은 기하 도형은 Codex 대신 칸 무늬 스크립트로 그린다.
- 원본 시안과 만드는 스크립트는 리소스 옆 `Source~/`에 둔다(Unity가 무시한다). 다시 만들 수 있어야 한다.
- 캐릭터 외형은 `VisitorTable.json` 행으로 등록한다(시트 칸 폭 104px, 앞·뒤·옆 × 숨쉬기 4 · 걷기 8 · 딴짓 + 눈 감은 숨쉬기(앞·옆), 손 높이 `handRatio`).
- **캐릭터 동작의 기준은 지금 동물들이다**(2026-09-29 확정: B3 걷기 8 · 몸 전체 숨쉬기 4 · 깜빡임 · 종마다 딴짓). 새 동물 · 새 동작도 AI로 그리지 않고 정지 그림 한 장을 부위로 조립하고(`Shop/Source~/make_anim.py`, 부위 좌표 `anim_specs.py`), 프레임 시간 · 움직임 폭(1~2칸)을 지금 동물에 맞춘다. 새 동물 = 정지 그림 앞·뒤·옆 + 부위 좌표 한 벌 + 딴짓 한 벌(`FIDGETS`, 종의 특징 부위 하나). 딴짓은 몸 높이를 바꾸지 않는다(든 빵이 따로 논다). 절차는 스킬 `asset-codex` 「캐릭터 동작」.

## 검수 (하나라도 어긋나면 다시)

- 외곽선 색·두께, 색 수(7색 안), 그라데이션 없음.
- 네 발로 선 듯 보이면 탈락. 옆모습이 앞모습보다 폭이 좁거나 눈이 높으면 탈락.
- 시트는 프레임마다 몸 크기·색·발끝 높이가 같다.
- 글자·바닥·그림자·테두리가 들어 있으면 탈락.
- 같은 화면의 다른 그림 옆에 세웠을 때 한 칸 크기가 같다.
