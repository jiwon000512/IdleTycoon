# 설계 08 — 존·입주·번식 (뽑기 삭제)

상태: 설계 · 2026-09-15
기능: 뽑기를 지운다. 맵의 존 3자리를 코인으로 열고, 빈 존에 종을 골라 입주시키면 번식 주기마다 한 마리씩 늘어나 존의 최대 마리 수에서 멈춘다. 시설(07)은 존 단위가 된다. 의상은 09, 저장·오프라인은 10.
기획서 대응: 2장 뽑기·존·입주·번식·시설·성장 축, 3장 루프 1~5, 4장 월드 존·존 팝업, 6.1·6.3·6.4, 8장 데이터 (v0.17)
다음 기능: 09 의상

---

### 1.3 흐름

```
GameManager.Update(1초) → Income.Tick → Zone.Tick
   └ 존마다 BreedProgress += dt → 주기 넘김 → ZooState.AddAnimal(zoneId) → ZonesChanged
        ├→ IncomeService 재계산 → IncomeChanged → 상단 바·관광객 수
        ├→ WorldPresenter.SyncAnimals → 그 존에 개체 스폰
        └→ ZonePopupPresenter(열려 있으면) 머리글·행 갱신
존 탭 → WorldCameraController.Tapped(땅 점) → WorldView.ZoneTapped(id) → MainScene → ZonePopupPresenter.Open(id)
   잠김 행 클릭 → ZoneService.TryOpen → OpenZone → ZonesChanged → WorldPresenter.SetLocked(false) → 팝업 빈 존 행으로
   종 행 클릭 → ZoneService.TryMoveIn → MoveIn(Count 1) → ZonesChanged → 스폰 → 팝업 시설 행으로
   시설 행 클릭 → FacilityService.TryUpgrade(zone, f) → FacilitiesChanged → 존 자식으로 시설 스폰
```
