# 설계 01 — 부트스트랩과 상단 바

상태: 검토 중 · 2026-09-14
기능: 앱을 켜면 테이블을 읽고 검증한 뒤 새 게임 상태(코인 300)를 만들고, 상단 바에 코인·초당 수입·동물원 레벨을 표시한다. 이후 모든 기능이 올라탈 뼈대.
기획서 대응: 4장 상단 바, 6.4 시작 상태, 데이터-테이블-규칙 7장
다음 기능: 02 가차(버튼·추첨·우리 격자·더미 스프라이트)

---

## 1. 코드 설계

### 1.1 계층 조정

Core 서비스가 레코드를 직접 읽어야 하므로 **레코드와 `GameTables`를 Core에 둔다.** Data는 `TableValidator`만. 코드-규칙 2장 표는 구현 후 이대로 고친다.

### 1.2 클래스

| # | 계층 | 클래스 | 책임 | 의존 |
|---|---|---|---|---|
| 1 | Core/Tables | `AnimalRecord`, `GradeRecord`, `ZooLevelRecord`, `GameConfig`(중첩: `StartConfig`, `CageGridConfig`, `GachaConfig`, `AnimalLevelConfig`, `PromotionConfig`, `OfflineConfig`) | JSON과 1:1 DTO. get/set 프로퍼티 | 없음 |
| 2 | Core/Tables | `GameTables` | 네 테이블 보관과 조회: `Animals`, `GetAnimal(id)`, `GetGrade(id)`, `ZooLevels`, `Config` | 1 |
| 3 | Core | `ZooState` | 상태 소유. `Coins`, `TotalCoinsEarned`, `PullCount`, `PromotionStage`, `PlacedAnimals`(id→level, 순서 유지), `WaitingRoom`, `LastSavedAtUtc`. 이번에는 `CreateNew(config)`, `AddCoins`, `TrySpendCoins`만 구현. 이벤트 `CoinsChanged(double)` | 1 |
| 4 | Core | `ZooLevelService` | `Level`, `CageCount`, `NextThreshold`(마지막 레벨이면 null), `IsPromotionUnlocked`. `Refresh()`로 `TotalCoinsEarned`에 맞춰 레벨 재계산. 이벤트 `ZooLevelReached(int)`. 대기실 입장은 02에서 추가 | 2, 3 |
| 5 | Core | `IncomeCalculator`(static) | `AnimalIncome(baseIncome, level, bonusPerLevel)`, `TotalIncomePerSecond(state, tables, promotionMultiplier)`. 이번 세션엔 동물이 없어 0 | 1, 2, 3 |
| 6 | Data | `TableValidator`(static) | `IReadOnlyList<string> Validate(GameTables)`: 데이터-테이블-규칙 7장(ID 유일·패턴, sortOrder 유일, grade 참조, 수입·가중치 범위, sprite 비어 있지 않음, 등급별 1종, 레벨 연속·단조 증가·첫 레벨 0, 홍보 해금 1개, 격자 ≥ 우리 수, 비용·성장률 범위, 시작 코인 ≥ 첫 비용) | 1, 2 |
| 7 | Game | `GameBootstrap`(MonoBehaviour, 씬에 1개) | `Awake`: `TableManager`로 4개 테이블 로드 → `GameTables` → `TableValidator`(오류 있으면 예외로 중단) → `ZooState.CreateNew` → `ZooLevelService` → `TopBarPresenter` 생성·`UIManager.Open<TopBarView>()` 연결. 이후 세션에서 서비스가 늘어나면 여기만 자란다 | 2, 3, 4, GameKit |
| 8 | UI | `TopBarView : UIView` | `[SerializeField]` TMP 텍스트 3개(코인, 초당 수입, 레벨/진행도). `SetCoins(string)`, `SetIncome(string)`, `SetZooLevel(string)` | GameKit.UI |
| 9 | UI | `TopBarPresenter`(순수 C#, IDisposable) | `CoinsChanged`·`ZooLevelReached` 구독 → View 갱신. 숫자 표기는 `BigNumberFormatter` | 3, 4, 8, 10 |
| 10 | UI | `BigNumberFormatter`(static) | `Format(double)` → `999`, `1.2K`, `3.4M`, `5.6B`, `7.8T` | 없음 |

의존 방향: UI → Game → Core, UI → Core. Presenter는 View 인터페이스가 아니라 View 클래스를 직접 받는다(구현이 하나뿐이므로 규칙대로 인터페이스를 만들지 않음).

### 1.3 씬·프리팹·리소스 (CLI로 생성)

| 대상 | 내용 |
|---|---|
| `Main.unity` | `GameBootstrap` 빈 오브젝트 추가. `EventSystem` + `InputSystemUIInputModule` 추가 |
| `Resources/UI/TopBarView.prefab` | 상단 고정 패널(1080×160). 좌: 코인, 중: 초당 수입, 우: 동물원 Lv와 진행도. 더미 배경색. TMP 기본 폰트 |
| 더미 리소스 | 이번 세션에는 없음(동물 스프라이트는 02에서) |

### 1.4 규칙 적용

- Core·Data는 UnityEngine 없음. 숫자는 `GameConfig`에서. 주석은 기획서 표 번호만.
- 이벤트 핸들러 이름 `State_CoinsChanged`, `ZooLevel_ZooLevelReached`. Presenter는 `Dispose`에서 해제.
- 예외는 테이블 검증 실패(부트스트랩 중단)와 잘못된 ID 조회에만.
