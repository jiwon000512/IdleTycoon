# 설계 07-3 — 타일맵과 1호점 맵

상태: 구현 완료 · 2026-09-16
기능: 눕는 바닥(잔디·흙·길)을 Unity Tilemap(Isometric Grid)으로 옮기고, 존을 6×8 타일 프리팹으로, 1호점을 존 10개 + 길 2칸 배치의 프리팹으로 만든다. 서 있는 것(울타리·시설·동물·관광객)은 07-2 그대로 스프라이트 + 화면 y 정렬.
기획서 대응: 4장 월드·시점, 8장 월드·아트 파이프라인 (v0.20)
논의: 월드 바닥 타일맵 논의 https://claude.ai/artifact/NGnSFjx5jiJ12bivD3dcZF · 1호점 맵 배치 https://claude.ai/artifact/5CQjyCzpgBRjvN9GDmL5La
다음 기능: 08 존·입주·번식

| D5 | 흙·잔디 경계 타일 없음 | 울타리가 경계를 가린다 |

### 0.2 설계 제안

| # | 제안 | 이유 |
|---|---|---|
| P1 | `Iso` 상수만 바꾼다(0.7071/0.3536 → 0.5/0.25). Unity Isometric Grid의 `CellToWorld`(cellSize 1×0.5)와 같은 식이라 셀 (x, z) = 논리 (x, z) | 두 좌표계가 하나 |
| P2 | `CageView` → **`ZoneView`**(파일·클래스 개명, meta GUID 유지). 바닥·길 `AddFlat` 삭제, 울타리 간격 1.0. 사각형은 프리팹 값: ground (−3,−4,6,8) · walk (−2.5,−3.5,5,7) · path (−4,−6,8,2)(존 앞 길 2칸, 좌우 1칸 여유) | 08의 개명을 앞당긴다 |
| P3 | **`BranchView`**(신규, 9줄): `m_mapArea`(Rect, 타일 좌표)·`m_zones[]`. `WorldView.m_cage` → `m_branch`, `Zone => m_branch.Zones[0]`(08까지 z01만), 카메라 범위 = `Iso.ToScreenBounds(MapArea)` + 여유 | 2호점은 다른 프리팹 |
| P4 | 프리팹 `Prefabs/Zone.prefab`(ZoneView + 울타리 스프라이트) · `Prefabs/Branch01.prefab`(BranchView → Grid(Isometric, 1×0.5) → Tilemap Ground(−2000)·Floor(−1000)·Path(−1500), tileAnchor (0.5,0.5) → Zone ×10, z01~z10 앞줄 왼쪽부터). 타일은 에디터 스크립트가 한 번 칠해 프리팹에 저장: 잔디는 맵 둘레 여유 6칸까지, 흙은 존 사각형, 길은 맵 안 나머지 | 씬에는 프리팹 인스턴스 하나. 이후 팔레트로 손질 가능 |
| P5 | 타일 더미 `Sprites/World/Tiles/{grass,dirt,path}.png`(64×32 마름모, PPU 64, 피벗 중앙, Point 필터) + `Tiles/{Grass,Dirt,Path}.asset`(Tile). 울타리 더미 `fence.png` 재생성(36×48, 한 칸 = 32px 오른쪽·16px 위, 피벗 기둥 밑). `zone_floor.png`·`zone_path.png`·`grass.png` 삭제 | D2 |
| P6 | 씬: `Cage`·`Grass` 삭제, `World` 아래 `Branch01` 인스턴스. 카메라 size 8 → 6, 시작 초점 = z01 중심 화면 좌표 근처 | 존 하나가 한 화면 |
| P7 | `facilities.json` 슬롯을 6×8 안으로(±2.2, ±2.8). 스키마 변경 없음 | 07 P7 "이동 영역 안 네 모서리" |

## 3. 구현 결과 (2026-09-16)

- 검증: 컴파일 0 · 콘솔 오류 0 · Q2 `GetCellCenterWorld(0,0)` = `Iso.ToScreen(0.5,0.5)` = (0, 0.25) · EditMode **98/98** · 플레이 캡처(웜뱃 3, 입간판·벤치, 관광객): 존 10개 흙 마름모 + 울타리, 사이 회색 길, 바깥 잔디, 동물이 z01 안, 앞 울타리가 동물 앞. 드래그 팬은 자동화하지 않았다.
- 캡처에서 고친 것: ① 타일 사이 틈(PIL 폴리곤 가장자리) → 행 단위 스팬으로 정확한 마름모. ② 웜뱃이 타일 2.5칸 크기 → `animals`·`visitors` scale 0.6. ③ 울타리 뒤 모서리 X자 교차(칸을 0.5 오프셋에 두고 가로대가 반 칸 초과) → 기둥을 정수 좌표에, 뒤 모서리(xMax, zMax)는 기둥 스프라이트 `fence_post.png`(P2 수정: `m_fenceStep` 삭제, `m_postSprite` 추가).
- 달라진 점: 카메라 초점 (−0.5, 1.25)(z01 중심 −1.5). `Tiles/` 폴더가 `Assets` 바로 아래(Tile 에셋). 에디터 스크립트 `BuildBranch.cs`·`PostSprite.cs`는 scratchpad에만.
