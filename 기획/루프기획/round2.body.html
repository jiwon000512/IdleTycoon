ZOO TYCOON · LOOP CONCEPTS · ROUND 2 · 2026-09-16

메인 루프 기획 2회차 — 남은 여섯을 엮다

1회차에서 남은 여섯(1 혈통 도감 · 2 소원 게시판 · 3 사육사 덱 · 5 탐험대 · 6 구조 보호소 · 8 후원자 편지)을 조합하고 심화해 열 개를 다시 냈다. 끌린다고 한 소원 게시판(2)을 먼저 한 단계 더 설계해 공통 척추로 삼고, 그 위에 나머지를 어떻게 얹느냐로 변주했다. 4·7·9·10은 메인 후보에서 빼고 미니 콘텐츠 후보로만 남긴다.

기획 10 · 장면 40장척추: 소원 게시판1회차 → 2회차

0공통 척추 — 소원 게시판 설계 초안

1회차에서 끌린 이유를 살리려면 "메뉴 퀘스트가 아니라 캐릭터가 말한다"는 형식과 "거절해도 손해 없다"는 원칙이 지켜져야 한다. 아래는 열 개 변주가 공유하는 규칙이다.

소원의 종류 (테이블 한 장)

  • 즉시형: 지금 가능한 것(벤치 놓기, 탭 케어 1회). 세션 안에 끝난다 → 3분 루프.
  • 시간형: 기다려야 하는 것(새끼 1마리, 8마리 채우기). 남은 시간이 약속이 된다 → 3일 루프.
  • 조건형: 상태 조합(흰 웜뱃 + 벤치, 두 종 동시 보유). 도감·변이·시설을 목표로 바꾼다.
  • 특별형: 변주마다 다르다 — 구조 요청(6), 탐험 의뢰(5), 혈통 주문(1·8).

생성 규칙

  • 게시판 슬롯 3~5. 새 소원은 관광객이 관람을 마칠 때 확률로 남긴다(화면에서 말풍선 → 게시판에 저장).
  • 생성기는 현재 상태를 읽어 "지금 가능한 것 2 : 시간 걸리는 것 2 : 어려운 것 1" 비율을 유지한다.
  • 수락은 동시에 3개까지. 거절·만료는 벌칙 없음. 만료된 소원은 다른 관광객이 다시 낼 수 있다.
  • 보상은 코인 대신 티켓·보전 포인트·의상 조각·단골 — 소원이 "코인 외 재화"의 출구다.

단골 → 후원자 사다리

  • 소원 성취 시 그 관광객은 단골(이름 획득, 재방문). 단골 N명이 새 관광객 종류·시설을 연다.
  • 단골의 소원을 3회 성취하면 후원자: 월 후원금 + 편지. 후원자 수가 2호점 조건.
  • 사다리 자체가 도감이자 장기 목표(장부 24명).

지켜야 할 것

  • 소원 문구는 짧게(12자 안). 문구 양이 콘텐츠 비용이므로 템플릿 + 이름 치환.
  • 소원이 자연 플레이와 어긋나면 잡일 — 생성기는 반드시 "지금 할 수 있는 것"을 포함.
  • 말풍선은 화면에 동시에 2개까지. 팝업 클릭 지옥(Zoo Park Story 불만)을 피한다.

01소원 → 혈통 (2 + 1)

소원이 번식의 목표를 정한다. "흰 웜뱃 보고 싶어요"가 게시판에 오르면 변이 보장 카운터와 남은 시간이 나란히 보이고, 성취 순간 관광객 앞에서 방생·포인트가 터진다. 코인은 확장, 포인트는 종·의상.

  • 3초새끼 팝, 변이 NEW, 성취 순간 코인 분수
  • 3분어느 소원을 잡을지, 방생할지
  • 3일보장 카운터·시간형 소원 만료
  • 돌아오는 이유"흰 웜뱃 소원 1일 남음"

차별점

  • 1회차 1번(혈통)에 목표 제공자를 붙였다. 도감의 빈 칸이 "누군가의 부탁"이 되어 자이가르닉 + 관계 동인이 겹친다.
  • Zoo 2·Pocket Frogs의 번식 수집에는 "왜 지금 이 색인가"가 없다. 여기선 소원이 순서를 준다.

적합 · 비용

  • 08 + 변이·pity·방생 + 소원 테이블·게시판 팝업. 중간
  • 소원이 확률(변이)에 걸리면 좌절 → 보장 카운터를 소원 기한 안에 맞춰 생성.

02단골 장부 (2 + 8)

소원을 내는 관광객에게 이름이 있다. 성취하면 단골이 되어 편지가 오고, 세 번 성취하면 후원자가 되어 월 후원금을 낸다. 장부 24명을 채우는 것이 동물원의 역사이자 장기 목표.

  • 3초봉투 열기, 관광객이 뛰며 코인
  • 3분누구의 소원을 먼저
  • 3일단골의 다음 소원(2일 뒤), 후원 정산
  • 돌아오는 이유새 편지·다음 소원 도착

차별점

  • 1회차 2번과 8번을 하나의 사다리로 묶었다. Animal Restaurant 손님 편지 + Hay Day 주문이 관계 단계(손님 → 단골 → 후원자)로 이어지는 형태는 참고작에 없다.
  • 후원금 = 무과금 우회 수입(고양이 오피스 빵공장 격)이면서 서사.

적합 · 비용

  • 관광객 개체에 이름·단계 저장, 편지 문구, 장부 UI. 중간
  • 관광객 종류 스프라이트 3종+ 필요. 문구는 템플릿 + 이름.

03후원 탐험 (8 + 5 + 1)

후원자의 부탁이 탐험 의뢰가 된다. "어릴 적 본 카피바라를 다시 보고 싶어요" → 후원금이 탐험 자금 → 사육사와 동행 동물이 알을 들고 귀환 → 부화하면 후원자가 보러 와 월 후원을 약속한다.

  • 3초출발·귀환 연출, 부화 팝
  • 3분어느 부탁을 탐험으로 풀지, 동행 선택
  • 3일탐험 3시간 → 부화 → 후원자 방문 → 다음 부탁
  • 돌아오는 이유귀환 시각, 부화 시각

차별점

  • 새 종 획득이 "돈 내고 사기"가 아니라 누군가의 기억을 되찾아 주는 일. Fallout Shelter 탐험 로그에 관계가 붙었다.
  • 후원자·탐험·번식이 한 줄기라 시스템 셋이 서로 이유가 된다.

적합 · 비용

  • 탐험지 테이블·타이머·일지 + 후원자. 중간~높음
  • 종이 적을 때(웜뱃 1종) 탐험 보상이 빈약 → 종 3개 이후에 켜는 기능.

04구조 게시판 (6 + 2 + 8)

게시판에 [구조] 칸이 있다. "도로에서 다친 웜뱃을 봤어요"를 받으면 임시 우리에서 회복시키고, 방사하면 명성, 정착시키면 번식 부모. 신고한 관광객은 단골이 되고, 명성이 수의사 후원자를 연다.

  • 3초케어 탭 하트, 방사 순간 숲으로
  • 3분받을까, 방사할까 정착할까
  • 3일회복 2~3일, 명성 레벨
  • 돌아오는 이유회복 게이지, 새 구조 요청

차별점

  • 1회차 6번(보호소)을 동물원의 일부로 축소했다. 전시 동물원 판타지를 유지하면서 "돌봄 서사"를 게시판 한 칸으로 넣는다.
  • 구조 동물이 정착하면 새 종 입주 경로가 하나 더 생겨 상점 의존을 줄인다.

적합 · 비용

  • 임시 우리(존 1개 예약)·회복 상태·명성. 중간
  • 다친 표현 아트(붕대 오버레이) 종당 1.

05사육사가 소원을 받아온다 (3 + 2)

소원은 사육사가 관광객에게서 받아온다. 사육사의 특기(접객·번식·시설·희귀)가 게시판에 오르는 소원의 종류와 보상을 정하고, 성취가 사육사 경험치가 되어 오프라인 상한·자동화가 열린다. 사육사가 늘수록 소원 폭이 넓어진다.

  • 3초사육사가 게시판으로 걸어가 붙이는 연출
  • 3분어느 사육사를 담당으로, 어느 소원을
  • 3일사육사 레벨·합류(동물원 Lv), 세트
  • 돌아오는 이유사육사가 받아둔 새 소원

차별점

  • 1회차 3번(덱)의 "카드 뽑기" 문제를 없앴다. 사육사는 동물원 레벨로 합류하고 소원 성취로 자란다.
  • Idle Miner 매니저는 숫자 배율인데, 여기선 매니저가 목표의 종류를 바꾼다.

적합 · 비용

  • 사육사 테이블·배치·경험치 + 소원. 중간
  • 사육사 스프라이트 1종 + 팔레트. 특기 종류가 적으면 차이가 안 보임(최소 4종).

06동물원 원정대 (5 + 3 + 1)

사육사가 원정 대장, 동물이 동행. 원정지마다 성공 확률이 보이고 실패는 없다(보상만 다름). 흰 동물을 데려가면 흰 알이 나오는 식으로 혈통이 원정으로 이어진다. 홈은 원정 중에도 돈다.

  • 3초편성 카드, 일지 넘기기, 부화
  • 3분누구를 데려갈지(동행 보너스 계산)
  • 3일원정지 해금, 대장 레벨, 흰 혈통 2종
  • 돌아오는 이유귀환 알림, 부화

차별점

  • 동물이 "전시품"에서 동료가 된다. 방치형 동물원에서 동물이 능동 역할을 갖는 안은 이것뿐.
  • 혈통(변이 유전)이 원정 결과에 연결되어 "흰 동물을 키울 이유"가 하나 더.

적합 · 비용

  • 원정·사육사·혈통 셋 — 2회차 중 가장 큼. 높음
  • 동행 동물이 존을 비우면 수입이 준다 → 동행은 "복제 카드"로(실제 개체는 남음).

07혈통 후원 (8 + 1 + 우두머리)

후원자가 혈통을 주문한다. "금빛 웜뱃이 있다면 사진집에 싣고 싶어요" → 번식 프로그램(부모 변이·만족도로 확률↑) → 탄생 → 이름을 지어 존 대표(우두머리) → 후원자가 사진집에 싣고 입간판에 걸린다.

  • 3초변이 탄생 연출, 이름 입력
  • 3분어느 부모를 남길지(변이 부모 유지)
  • 3일보장 12회, 후원 예약 성취
  • 돌아오는 이유주문이 걸린 번식 결과

차별점

  • 1회차 1번에 "누구를 위해"와 "이름 있는 개체"를 붙였다. 1회차 7번(머지)의 우두머리 애착만 떼어 왔다.
  • "부모 변이 유지 → 확률↑"가 방생 결정에 무게를 준다(흰 부모는 방생하지 않는다).

적합 · 비용

  • 변이 유전 규칙 + 이름 저장 + 후원자. 중간
  • 변이 색이 적으면 주문이 금방 바닥 → 종당 3색.

08통합안 — 소원 척추 위에 넷 (2 + 1 + 3 + 8)

가장 넓은 안. 소원이 D1 튜토리얼, 번식·변이가 소원의 재료(D3), 사육사가 소원 폭과 자동화를 넓히고(D7), 후원자 장부가 2호점 조건(D30). 리셋 없음, 1호점 수입 유지.

  • 3초새끼 팝·성취 코인·봉투
  • 3분소원 선택 + 방생/구매 하나
  • 3일보장 카운터·사육사 레벨·편지
  • 돌아오는 이유소원 시간, 후원 정산, 2호점 조건

차별점

  • 조사의 "세 겹 루프"를 D1/D3/D7/D30에 맞춰 기능을 켜는 순서로 배치했다. 고양이 오피스의 "구역 → 회사 → 직원" 사다리에 대응하는 우리 사다리는 "소원 → 혈통 → 사육사 → 후원자".
  • 레퍼런스와 다른 점: 목표(소원)와 성장(번식)과 관계(후원자)가 같은 관광객에서 나온다.

적합 · 비용

  • 넷 다 — 출시 범위가 커진다. 높음 단, 켜는 순서대로 만들면 08~11 로드맵과 겹친다.
  • 기능 넷이 "같은 자리"를 다투지 않는지: 소원(목표)·혈통(경제)·사육사(자동화)·후원자(서사) — 자리가 다르다.

09리모델링 의뢰 (2 + 시설·만족도)

소원 중 시설·꾸미기 의뢰를 중심에 둔다. "쉴 곳이 없어요"에 벤치를 놓으면 존 만족도 ★가 오르고, ★가 번식·기부·셀카를 연다. 소원은 ★가 낮은 존을 가리켜 다음 할 일을 알려준다. 07 시설을 살리는 안.

  • 3초시설 설치 연출, ★ 오르는 팝
  • 3분어느 존을 먼저 꾸밀지
  • 3일존 ★★★ 완성, 단골
  • 돌아오는 이유새 리모델링 소원

차별점

  • Planet Zoo 복지 → 관람객 반응을 방치형 ★ 하나로 압축. 시설이 "수입 배수 버튼"에서 동물원의 얼굴이 된다.
  • "존이 다 똑같다" 불만(Idle Zoo Park)에 대한 직접 답.

적합 · 비용

  • 07 시설에 ★ 계산 + 소원. 낮음~중간
  • 시설 아트가 종류마다 필요(4종은 이미 더미). 혼자서는 경제 축이 약해 1·2와 묶여야 한다.

10구조 원정대 (6 + 5)

원정의 목적이 구조다. "강가에 다친 카피바라"를 대장(수의 특기)이 구하러 가고, 돌아와 회복시킨 뒤 방사(명성) 또는 정착(번식 부모). 도감은 "가진 동물"이 아니라 "만난 동물" 기준.

  • 3초구조 일지, 케어 탭, 방사
  • 3분어느 요청을, 누구를 보낼지
  • 3일원정 + 회복 = 2~3일 리듬
  • 돌아오는 이유귀환·회복 시각

차별점

  • 1회차 6번과 5번을 합쳐 "동물원 = 야생 구조 기지". 참고작 없음. 정착 동물이 번식 부모가 되어 기존 루프로 합류.
  • "만난 동물 도감"은 소유하지 않은 종도 채워 도감 수명이 길다.

적합 · 비용

  • 원정·회복·명성. 중간~높음
  • 전시 동물원과 구조 기지 사이에서 정체성이 흔들릴 수 있음 → 구조는 존 하나 + 게시판 칸으로 제한(4번 안)이 안전.

내 읽기

  • 열 개는 사실 한 게임의 층으로 읽힌다: 1(경제) → 2·9(목표) → 5·7(자동화·애착) → 3·4·6·10(중기 콘텐츠) → 8(전체 사다리). 서로 배타적인 것은 3·6·10(탐험/원정 계열 중 하나)과 4·10(구조 계열 중 하나)뿐이다.
  • 가장 작은 출시 가능 조합은 1 + 2 + 9: 소원 게시판(목표) + 혈통(경제·수집) + 시설 ★(존의 얼굴). 셋 다 중간 이하 비용이고 08~11 로드맵과 겹친다.
  • 차별성 최상위는 6(동물이 동료)과 10(구조 기지)인데 둘 다 비용이 높고 정체성을 바꾼다. 하나를 출시 후 첫 대형 업데이트로 두는 게 맞아 보인다.
