# 타이쿤 밖에서 훔쳐올 루프 — 동물원 격자 위의 "10초마다 손"과 "부재중"

전제: 현재 루프는 가차 → 존 배치(한 존 한 종) → 번식 → 초당 수입, 관광객이 길을 걷고 존 밖에 숲 12칸이 있다. 아래는 각 루프 계열을 이 격자에 얹었을 때 **손이 10초마다 무엇을 하고, 부재중에 무엇이 일어나는가**만 추린 것이다. 비용은 1인·Unity·현 코드베이스(타일맵·존 프리팹·관광객 이동 있음) 기준의 추정이다.

## 1. 타일 배치 점수 — Dorfromantik · Islanders · Carcassonne · Townscaper · Terra Nil · Kingdom

## 3. 방치 + 덱/전략 — Loop Hero · Slay the Spire · Backpack Hero

| 항목 | 내용 |
|---|---|
| 핵심 루프 | Loop Hero: 영웅은 루프를 자동으로 돌며 싸운다. 플레이어는 전리품 카드를 루프 옆에 놓아 세계를 바꾼다(산을 붙이면 체력 보너스+새 적). 카드가 쌓이면 보스. 한 바퀴마다 "귀환(자원 보존) vs 계속" → 캠프 건설. 출발점은 2019년 팀 내 "제로 플레이어 게임" 논의. StS: 전투 후 3장 중 1장, 유물, 갈림길. Backpack Hero: 격자 인벤에서 아이템의 위치·인접이 전투 효과. |
| 손 | 3장 중 1장 + 놓을 칸 = 10초 1결정. 나머지는 자동. |
| 왜 재미있나 | 자동 진행이 "결과를 보는 시간"을 만들고 배치 하나가 다음 바퀴 결과를 바꾼다 → 결정 밀도는 낮고 결과 밀도는 높다. 귀환 결정이 세션 종료를 능동적 선택으로 만든다. |
| 동물원 격자에 | 관광객이 이미 길을 돈다 = 루프. 카드 = 길 옆 타일(매점·벤치·그늘나무·포토존). 인접 규칙: 벤치 2+그늘 = 체류↑, 매점 옆 존 = 그 존 수입↑. 카드는 관광객 지출로 드로우, 손패 상한. "하루 마감" = 귀환: 손패를 비우고 보너스 확정. Backpack식: 존 내부 3×3에 사육 도구(물통 옆 진흙 = 하마 만족). |
| 방치 결합 | 오프라인에도 관광객이 루프를 돌아 수입, 카드가 상한까지 쌓임 → 복귀 시 "카드 N장 놓기" 세션. |
| 비용 | 중간. 카드 드로우 UI + 인접 규칙; 관광객 시스템 재사용. |
| 성과 | Loop Hero: 4인, 첫날 동접 3.2만, 첫 주 50만 장, 2021.12.8 100만 장, 모바일 2024.4, Steam 리뷰 16,098개 91%, TGA 2021 인디 후보. StS: 2인, 2018.6 100만·2019.3 150만, iOS 2020.6·Android 2021.2. Backpack Hero: 킥스타터 $223,893(목표 $20,000), 메타 76. |

## 4. 손이 있는 수집 시뮬 — Viva Piñata · Slime Rancher · Neko Atsume · Pokémon Snap · Ooblets

| 항목 | 내용 |

## 6. 타이밍 미니게임 — Stardew · 동물의 숲 · Cooking Mama · Good Pizza, Great Pizza

| 항목 | 내용 |
|---|---|
| 핵심 루프 | Stardew 낚시: 초록 바(레벨 0에서 96px, 레벨당 +8px) 안에 물고기를 유지해 게이지 완충. 한 번도 안 벗어나면 Perfect = 품질 1단계↑·경험치 ×2.4. 보물상자 기본 15%. 동숲: 찌가 가라앉는 순간 탭 1회, 최대 5회 입질·4회 후 확정, 그림자 크기 = 종. Cooking Mama: 단계별 10초 미만 미니게임, 평균으로 메달, 실패해도 "Mama가 고쳐줄게". GPGP: 주문 듣기 → 토핑 → 오븐 → 팁, 손님 100명+. |
| 손 | 탭 1회(동숲) 또는 바 유지(Stardew), 10초 이내. |
| 왜 재미있나 | 짧고 실패 비용 0, 성공은 품질·배율 보너스로만 → 선택적 숙련. 장비·레벨이 바를 키워 성장이 손에 느껴진다. |

## 7. 동물원 격자 + 번식 + 관광객과 가장 맞는 6개

| 순위 | 루프 | 10초마다 손 / 부재중 | 이유 |
|---|---|---|---|
| 1 | Loop Hero식 길 옆 카드 | 3장 중 1장을 길 옆에 배치 / 관광객이 돌며 수입, 카드 축적 | 관광객 루프가 이미 있어 "자동 진행 + 배치" 구조가 그대로 겹침. 결정 1개, 결과는 다음 바퀴에. |
| 2 | Viva Piñata식 조건 → 실루엣 → 정주 → 번식 | 존 주변 타일·먹이로 조건 채우기 / 실루엣 방문 로그 | 숲 12칸이 야생. 번식과 가장 직결되고 가차 밖 획득 경로가 생긴다. |
| 3 | Dorfromantik식 존 인접 서식지 점수 + 보드 위 퀘스트 | 환경 타일 1장 배치 / 타일이 손패에 쌓임 | 타일맵을 그대로 쓰고 점수가 읽힌다. "판다는 대나무 3칸"이 곧 튜토리얼. |
| 4 | Neko Atsume + Snap 부재중 방문·사진 | 굿즈 배치, 희귀 행동 촬영 / 방문·선물·사진 | 오프라인 루프에 이야기와 복귀 이유를 준다. 비용 낮음. |
| 5 | Terra Nil식 '야생 방사' 프레스티지 | 만원 존 방사 결정 / 영구 배율 유지 | 프레스티지를 보전 동물원 테마로 읽히게 한다. 끝이 있는 존이 "한 존 더"를 만든다. |
| 6 | 동숲/Stardew식 타이밍 먹이주기 | 탭 1회, Perfect면 버프 / 버프만 시간제 지속 | 선택적 숙련 보너스, 구현이 가장 싸다. |

보류: 머지 보드(비용 높음·별도 UI·라이브옵스 의존, 현 번식이 이미 머지), Backpack Hero식 존 내부 격자(2·3위와 겹침), Unpacking식 꾸미기(아크라 루프가 약함, 소품 아트 부담).
