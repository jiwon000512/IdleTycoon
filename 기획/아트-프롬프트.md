# 아트 공통 규칙 (2026-09-18)

모든 아트는 이 장을 먼저 따른다. 동물·월드 프롬프트는 아래 두 부에 있다. 생성은 에이전트가 Codex CLI(stdin 프롬프트 + `-i` 참조)로 직접 뽑고, 후처리는 Windows Python(Pillow)으로 한다.

## 0. 스타일 가이드 (모든 생성 프롬프트 앞에 붙인다)

기준 결은 사용자가 그린 웜뱃(`Resources/Sprites/Animals/Wombat/Wombat.png`)이고, 굴(`Burrow/Source~/burrow_1.png`)이 같은 결이다(2026-09-18 측정: 둘 다 세로 약 40칸, 외곽선 같은 색). 논의 기록 https://claude.ai/artifact/HHzxLaVcZaMcM4wnsRWVXy .

**AI 정확도를 지키는 세 규칙 (2026-09-18 확정)**

1. **참조는 결만 주는 사물 이미지.** 동물을 뽑을 때 웜뱃을 단독 참조로 주지 않는다. 웜뱃을 주면 다른 종도 웜뱃 모양으로 베낀다(카피바라 테스트 2장 중 1장 실패, 1장 반쯤 섞임). 굴 원본 같은 사물을 참조로 주고 종·자세는 문장으로 지정한다. 웜뱃 자신을 뽑을 때만 웜뱃을 참조로 준다.
2. **격자는 후처리가 강제한다.** 생성은 긴 변 약 40~60칸으로 요청한다(AI가 가장 안정적인 크기. 70칸 가까이 가면 격자가 흐트러진다). `Sprites/World/Source~/make_pixel.py`가 칸마다 최빈색으로 모은 뒤 한 칸 = PX 픽셀로 정수 배 확대한다. 같은 묶음(굴 1·2·3단계)은 `--cellsw`로 같은 칸 수를 준다(격자 자동 측정은 반 주기를 잡기도 한다). 칸이 커지면 원본의 2칸 외곽선이 굵어지므로 `--thin`으로 바깥 외곽선을 1칸으로 줄인다(굴에 적용).
3. **한 화면 안에서 한 칸 크기가 같다.** 칸 크기는 화면마다 정한다.

| 화면 | 한 칸 | 적용 |
|---|---|---|
| 지상(존 맵) | 서 있는 것 **4×4 px**, 눕는 타일 **4×2 px**(아이소 2:1, `make_tiles.py --k=2`, G=48). PPU 64 | 굴 1·2·3(62칸 폭 = 248px), 굴 바닥 `yard`. **나무·잔디·길은 아직 옛 격자**(나무 약 2px) — 나무를 지금 크기로 4px 격자에 맞추면 11~22칸밖에 안 돼 외곽선이 사라져 보류. 다시 뽑을 때 맞춘다 |
| 가게 내부 | **유닛(웜뱃·손님) 기본 크기 = 한 칸 2px · PPU 80 · 스케일 1**(2026-09-18 확정). 42칸 캐릭터 ≈ 1.05유닛. 크기는 스케일이 아니라 PPU로 정한다. 소품은 아직 PPU 64 더미 — 다시 뽑을 때 PPU 80에 맞춘다 | 웜뱃 정면·뒷모습(84×88px) |

|---|---|

| 외곽선 | **서 있는 것(동물·관광객·울타리·시설·자물쇠·나무)은 진갈색 (52,32,32) 약 2px 외곽선 필수.** 검정·얇은 선은 탈락 |

| 배경 | 순백 단색, 바닥·텍스트·테두리·워터마크 없음. 시트는 프레임 사이에 빈 흰 공간 |
| 피벗·PPU | 서 있는 것은 하단 중앙(발끝·기둥 밑), 타일은 중앙. PPU는 동물 300 · 타일과 월드 소품 64 · 시설 128 |

## 1. 절차: 시안 비교 → 선택 → 굽기

한 리소스에 프리팹 굽기는 한 번만 한다. 사람이 처음 보는 시점을 굽기 뒤가 아니라 앞으로 당긴다.

1. 같은 프롬프트(또는 변형 3개)로 **3장** 생성, 후처리(배경 투명·팔레트·축소)까지만 한다.
2. 최근 게임 캡처 위에 3장을 실제 크기로 합성한 **비교 페이지(아티팩트)**를 만들어 사용자에게 보인다. 타일은 3×3칸을 깔아 이음새를 보이고, 서 있는 것은 웜뱃 옆에 세운다.
3. 사용자가 하나를 고르면(또는 수정 지시) 그때 임포트 설정·프리팹 굽기(`ZooTycoon/Bake/...`)를 **한 번** 한다.
4. 굽기 뒤 캡처 1장으로 확인. 여기서 다시 뽑는 일은 색·크기 같은 수치 조정만이어야 한다.
5. 고른 시안의 **부분 수정**("여기만 다듬어")은 다시 뽑지 않고 격자 PNG를 칸 단위로 직접 고친다(재생성은 얼굴·색까지 흔들린다). 확정되면 시안 비교 아티팩트는 지운다.

**시점 (2026-09-18)**: 가게 화면 캐릭터는 **위 30도에서 내려다본** 모습. 정면·뒷모습 모두 같은 카메라라 둘 다 위 30도다(뒷모습을 아래에서 올려다보면 카메라가 둘이 된다). 방향은 캐릭터가 도는 것으로만 바꾼다.

원본 생성물과 후처리 스크립트는 리소스 옆 `Source~/`에 둔다(`Tiles/Source~/make_tiles.py`, `World/Source~/make_pixel.py`. `make_sprite.py`는 격자를 강제하지 않는 옛 스크립트). 타일 시트는 에디터 메뉴 `ZooTycoon/Bake/Import Yard Tiles`(`TileSheetImporter.Import(시트, 접두어)`)로 Tile 에셋 18장을 만든다.

## 2. 검수 기준 (공통, 하나라도 어긋나면 다시 뽑는다)

- 외곽선: 서 있는 것은 (52,32,32) 2px, 눕는 것은 없음.
- 색이 7개를 넘거나 그라데이션·디더링이 보이면 탈락. 후처리 팔레트 축소 뒤 기준.
- 눕는 텍스처는 seamless(3×3으로 깔았을 때 이음새·격자 반복이 눈에 띄면 탈락. 잔디 꽃 3송이 반복이 이 경우).
- 시트는 정확히 6프레임 1행, 프레임 사이 빈 공간, 프레임마다 몸 크기·색 동일, 발끝 높이 동일.
- 텍스트·바닥·그림자·테두리가 들어 있으면 탈락.
- 같은 화면의 다른 에셋 옆에 세웠을 때 한 칸 크기가 같아야 한다(0장 규칙 3). `make_pixel.py`를 거치면 보장된다.

# 동물 캐릭터 이미지 생성 프롬프트 (웜뱃 기준)

기준 리소스: `Resources/Sprites/Animals/Wombat/`. 새 종은 아래 3개 프롬프트를 순서대로 돌려 정지 1장 → Idle 시트 → Move 시트를 만든다.
**매번 웜뱃 정지 그림(`Wombat.png`)을 참조 이미지로 같이 첨부한다.** 첫 프롬프트로 정지 그림이 나오면, 그 뒤 시트 프롬프트에는 웜뱃 대신 **방금 만든 정지 그림**을 첨부한다(종 안에서 모양이 흔들리지 않게).

`{ANIMAL}` 자리에 종 이름, `{FEATURES}` 자리에 그 종을 구분하는 특징 2~3개를 넣는다.

## 0. 공통 스타일 블록 (모든 프롬프트 앞에 붙임)

```
Chunky pixel art game sprite, exactly the same art style as the attached reference image.
Style rules:
- large blocky pixels on a roughly 40x40 pixel grid, crisp square pixels, no anti-aliasing, no blur
- thick dark brown outline (about 2 pixels wide) around the whole silhouette, same outline color as the reference
- soft, low-saturation pastel palette with only 5-7 flat colors, no gradients, no dithering
- one flat shadow tone on the belly and far legs, one small white highlight stroke on the top of the head
- cute, round, chubby proportions: big head, tiny dot eye, small simple smile, short stubby legs
- 3/4 side view facing right, standing on an invisible flat ground, feet at the very bottom of the body
- plain solid white background, no ground, no shadow on the ground, no text, no border, no watermark
```

## 1. 정지 그림 (`<종>.png`, Single)


## 2. Idle 시트 (`<종>_Idle.png`, 6프레임 가로 1행)

```

Sprite sheet: 6 frames of the attached {ANIMAL} in ONE horizontal row, left to right.

All 6 frames are the same size and the same character with identical colors and outline.
Leave a clear gap of empty white space between frames. Wide image 2048x768.
```

# 월드 리소스 이미지 생성 프롬프트 (쿼터뷰, 설계 07-2)

월드는 순수 2D 쿼터뷰(2:1)다. 바닥·길·잔디처럼 **눕는 것**은 위에서 똑바로 내려다본 seamless 텍스처만 만들면 에이전트가 마름모(평행사변형)로 눌러 넣는다. 울타리·시설·자물쇠처럼 **서 있는 것**만 쿼터뷰 각도로 생성한다. 지금은 전부 더미가 들어 있고, 같은 경로에 덮어쓰면 된다.

## 0. 공통 스타일 블록 (물체용)

```
Chunky pixel art game asset, same art style as the attached reference image (the wombat sprite).
Style rules:
- large blocky pixels, crisp square pixels, no anti-aliasing, no blur
- thick dark brown outline (about 2 pixels wide) around the silhouette
- soft, low-saturation pastel palette, 5-7 flat colors, no gradients, no dithering
- plain solid white background, no ground, no cast shadow, no text, no border, no watermark
```

## 1. 눕는 텍스처 3장 (에이전트가 마름모로 변환)

| 파일 | 프롬프트 | 결과 |
|---|---|---|

| `Sprites/World/grass.png` (잔디 배경) | `Seamless tileable top-down pixel art texture of short green lawn grass, soft muted green, tiny lighter blades scattered, flat lighting, viewed straight from above, square 512x512.` | 그대로 타일 |

## 2. 울타리 한 칸 (`Sprites/World/fence.png`)

기둥 하나 + 기둥 오른쪽에서 **오른쪽 위로 2:1 각도(가로 2 : 세로 1)로 올라가는 가로대**. 가로대는 이미지 오른쪽 끝까지 닿아야 다음 칸의 기둥에 붙는다. 왼쪽·오른쪽 변은 이 그림을 좌우 반전해서 쓴다.

```
[공통 스타일 블록]
Subject: ONE section of a low wooden zoo fence for an isometric (2:1) game, seen from the front-right isometric angle.
A single vertical wooden post on the LEFT, and two horizontal wooden rails that start at the post and go to the RIGHT and slightly UP at exactly a 2:1 isometric slope (2 pixels right for every 1 pixel up), reaching the right edge of the image.
The rails must end exactly at the right edge so the piece tiles with the next post. Post height about twice the rail span height.
Square image 1024x1024, the post bottom touching the bottom edge.
```

검수: 가로대 기울기가 2:1인가(더 가파르거나 완만하면 다음 칸과 안 맞는다). 기둥이 왼쪽 끝에 있는가. 에이전트가 배경 제거 → 피벗 = 기둥 밑 중앙 → 폭을 0.96유닛에 맞춰 PPU 계산.

## 3. 시설 4종 (`Resources/Sprites/Facilities/{Sign,Bench,Shop,Tree}/*.png`)

서 있는 물체라 3/4 쿼터뷰 각도로. 하나씩 생성하고 웜뱃을 참조 이미지로 첨부해 크기·픽셀 밀도를 맞춘다.

```
[공통 스타일 블록]
Subject: {OBJECT} for a cute zoo, drawn for an isometric (2:1) game from the front-right 3/4 view so that the front face and the right side face are both visible, top surface slightly visible.
Single object, centered, standing on an invisible flat ground, the base touching the bottom of the object.
Square image 1024x1024.
```

| 파일 | `{OBJECT}` |
|---|---|
| `Sign/Sign.png` | `a wooden promotional sign board on two short posts, with a blank light panel` |
| `Bench/Bench.png` | `a small wooden park bench with a backrest` |
| `Shop/Shop.png` | `a tiny snack kiosk with a red-and-white striped awning and a counter` |
| `Tree/Tree.png` | `a round leafy tree with a short brown trunk` |

## 5. 뽑은 뒤 처리 (에이전트가 함)

흰 배경 제거 → 눕는 텍스처는 `Iso` 비율(가로 2 : 세로 1)로 평행사변형 변환 → 피벗·PPU 설정(바닥·길 중앙, 울타리 기둥 밑, 시설·자물쇠 하단 중앙) → 같은 경로에 저장. 사용자는 PNG만 넣으면 된다.
