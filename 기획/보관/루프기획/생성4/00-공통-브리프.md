# 루프 기획 4회차 — 생성 에이전트 공통 브리프

## 게임

1인 개발 모바일 **세로 화면 방치형 동물원 타이쿤**. Unity 2D 쿼터뷰(마름모 타일), 코지 픽셀아트 톤. 한 손 조작(탭·드래그·팬).

지금 구현돼 있는 것:
- 1호점 맵: **존 3×3**(존 = 6×8 타일의 울타리 우리, 바닥은 흙), 존 사이와 둘레에 **2칸 폭 길**, 맵 둘레 **숲 띠 12칸**(나무·덤불 1,330개), 그 밖은 무한 잔디.
- 동물 1종(웜뱃, idle·move 애니). 동물은 존 안을 돌아다닌다. 앞으로 종이 늘어난다.
- **관광객**이 길을 걷다 동물이 있는 우리 앞에서 멈춰 구경하고 코인이 뜬다. 관광객 수 = f(초당 수입).
- 수입 틱 1초(초당 수입 = 동물 × 시설 배수). 시설 4종(간판·벤치·매점·나무)을 존 모서리 슬롯에 놓고 단계 업그레이드.
- 카메라 팬. 조작은 탭과 팬뿐.

기획 방향(확정): 존 개장 → 종 입주 → 번식(마리 수 증가, 오프라인 포함) → 의상. **리셋형 환생 없음, 강제 광고 없음, 에너지·부재 페널티 없음.** 오프라인 수익 있음.

## 제약

- 1인 개발. 새 아트는 작은 픽셀 스프라이트 몇 장 수준(이미지 생성 파이프라인 있음). 새 UI 화면은 1~2개까지.
- 세로 한 손. 탭·드래그만. 가상 패드 금지.
- 규칙·숫자는 JSON 테이블로 표현 가능해야 한다.
- 방치형의 편안함을 깨지 않는다(안 해도 손해 없음, 돌아오면 할 게 있음).

## 이미 나온 30개 — 전부 금지(변형 포함)

1회차: 혈통 도감(번식=수집·변이·pity·방생) / 소원 게시판(관광객이 목표를 줌) / 사육사 덱(사람이 카드) / 동물원의 하루(아침·낮·밤) / 탐험대(원정으로 종 획득) / 구조 보호소(돌봄·방사·명성) / 머지 우리 / 후원자 편지(관광객 서사) / 사계절 달력(28일 주기) / 사진 의뢰.
2회차: 위 1·2·3·5·6·8의 조합·심화 10개(소원+혈통+시설★ 등).
3회차: 곡괭이 사육사(캐릭터가 걸어 다니며 개간) / 개척 퍼레이드(자동 전진 + 버튼 연타) / 먹이 던지기와 드롭 쓸어담기 / 책상 위 동물원(켜 두는 화면·관찰 일지) / 하루 세 번의 손(타이밍·연타·드래그 미니 조작) / 길 옆 카드(3택1 배치·인접 콤보) / 숲의 실루엣(조건 → 야생동물 방문 → 정주) / 서식지 타일(존 안 타일 배치 퍼즐) / 강화 연타(대기줄 = 벽, 3축 업그레이드, 합성) / 소원이 손을 부른다(행동형 소원).

장르 공통 클리셰도 금지: 환생·프레스티지, 연구 트리, 일일 퀘스트·출석, 시즌 패스, VIP 손님, 매니저 자동화, 이벤트 한정 동물, 미니게임 모음, 길드·친구 방문, 광고 2배.

## 사용자의 불만(이번 회차가 풀어야 할 것)

"기존 레퍼런스를 참고하는 데서 끝난다. 타이쿤 안에서 소거·합성만 하는 것 같다." → **어떤 게임에서 봤는지 이름을 댈 수 있는 아이디어는 실패**다.

## 출력 형식 (아이디어 하나당)

```
### N. 이름
- 규칙: 2~4문장. 기능 이름이 아니라 규칙으로. 숫자 예시 포함. ("교배 시스템" ✗ → "인접한 두 존의 종이 먹이그물에서 이어져 있으면 …" ✓)
- 새 고민: 이 규칙 때문에 플레이어가 새로 하게 되는 결정·저울질 한 줄. 없으면 그 아이디어는 버린다.
- 가장 비슷한 것 / 구조적 차이: 기존 게임(또는 시스템) 하나와, 그것과 구조가 어떻게 다른지.
- 동물원 필연성: 공장·식당·카페 타이쿤으로 소재를 바꾸면 왜 성립하지 않는가.
- 방치 연결: 자리를 비운 동안 무엇이 일어나고, 돌아온 첫 30초에 무엇을 하는가.
- 새로 필요: 아트 n장 · UI 화면 n개 · 테이블 n개.
```

뻔한 것부터 나오므로 **많이 낸 뒤 스스로 줄여라.** 최종 12개만 남기고, 버린 것들은 이름과 버린 이유를 한 줄씩 끝에 붙인다.
