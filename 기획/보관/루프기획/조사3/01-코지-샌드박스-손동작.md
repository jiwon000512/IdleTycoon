# 코지 샌드박스의 "10초 손동작"과 방치 연결 — 조사 보고

> 조사 제약: 세션 웹검색 한도가 소진돼 검색 3회 + 직접 URL 열람 약 45회(위키·Steam·개발자 인터뷰·리뷰)로 진행. Deconstructor of Fun은 Hay Day 인터뷰 1편만 열람 가능. 못 연 출처는 "(추정)"으로 표시.

## 0. 한 줄 결론

**손은 "아직 자동화되지 않은 일"을 하고, 진행이란 그 손을 봇·시설로 사서 대체하는 것이다.** Rusty's Retirement(초반엔 5–10분마다 씨앗을 직접 심다가 로봇을 사면 "90%가 자동"), Forager(손으로 캐다가 industry 트리로 로봇), Slime Rancher(손으로 먹이 주다가 auto-feeder·드론)가 전부 같은 구조다. 사랑받는 게임은 손동작을 **유지보수(물주기·청소)** 가 아니라 **수확 폭발·배치·돌봄**의 큰 순간에 남기고, 자리 비운 동안의 손해는 만들지 않는다(Farm Together "오프라인에도 시간이 흐른다", Hay Day "작물은 절대 죽지 않는다", 동물의 숲 NH "제작·조경 대기시간 제거").

## 1. 핵심 7개 게임

### Stardew Valley (2016, ConcernedApe)

| 항목 | 내용 |
|---|---|
| 손이 하는 것 | 타일에 도구 1회: 괭이·도끼·곡괭이·물뿌리개 각 **2 에너지**, 낚싯대 8, 낫 0. 즉시 파괴·드롭·자동 줍기. 업그레이드하면 **범위가 커짐**(구리 3칸 일직선 → 강철 5칸 → 금 3×3 → 이리듐 6×3; 이리듐 물뿌리개 100회) — 손이 바빠지는 게 아니라 커진다 |
| 대기·방치 | 작물은 **하루 단위**로 자람(파스닙 4일). 자리 비운 동안은 아무것도 안 자람(게임 내 시간만) |
| 하루·세션 | 6시–새벽 2시 = 실시간 **약 14분**(게임 1분 = 0.7초). 에너지 최대 270(스타드롭 +34씩, 최대 508). 메뉴·대화·낚시 중 시간 정지. **저장은 잠들 때만** → "한 번만 더" 압력. 2시에 쓰러지면 회복 50%, 밖에서 쓰러지면 돈 10%(최대 1000g) 손실 |
| 진행 축 | 도구 등급 → 범위, 스킬 레벨 → 에너지 절감(레벨당 0.1), 스프링클러로 물주기 자동화, 관계·광산·커뮤니티센터 |
| 사랑받은 이유 | 5,000만 장(2026-02). 분석글: 활동마다 다른 보상 주기가 겹쳐 "before you know it, you get hooked". 반대로 "하루를 min-max하려는 사람에겐 상시 불안"이 느긋한 분위기와 충돌(Kokutech, 검색 요약) |
| 터치 적합성 | 모바일(The Secret Police, iOS 2018-10·Android 2019-03, iOS 메타 88): **탭 이동** 기본, **자원 노드를 탭하면 도구 자동 선택**(낫 제외), NPC·동물 탭하면 다가가 상호작용, 선물 들고 있으면 자동 선물. Pocket Gamer: "대부분 탭 한 번으로", 단 전투는 "거의 못 쓸 수준" |
| 동물원 대입 | 우리 탭 → 알맞은 행동(먹이/청소/쓰다듬기) 자동 선택. 에너지·낮밤은 도입 말고 "도구 범위 성장"만 가져온다 |

### Rusty's Retirement (2024, Mister Morris Games) — 가장 선명한 idle+손 하이브리드

| 항목 | 내용 |
|---|---|
| 손이 하는 것 | 씨앗 심기·밭 정리 지시, **거대 작물 클릭하면 여러 개**, 구조물 톱니 **5번 돌려** 부품 획득, 채소·벌통 언락, 봇 업그레이드, 장식 배치. 리뷰: "**초반엔 5–10분마다 씨앗**을 놓아야 하지만 로봇을 사면 90%가 자동" |
| 대기·방치 | 8종 봇(물주기·수확·바이오연료·비료·동물 먹이 등, Splunk는 빈 밭 자동 파종). 작물→코인+바이오연료→부품→건물/장식. **Focus Mode**는 생산을 느리게 해 "안심하고 무시" 가능 |
| 하루·세션 | 낮밤 없음. 화면 하단/측면 1/4 크기 오버레이로 **종일 켜 둠**(리뷰어: "며칠 내내 켜 둠", "Zoom 회의 중에도") |
| 진행 축 | 봇 종류·속도, 주민 집(기능 언락), 지형(늪·사막·숲) |
| 사랑받은 이유 | 첫 주 10만, 2025-07 55만 장, Steam 97%(6,582). PC Gamer "수동적 설계가 차별점", RPS "멀티태스킹 덕에 중독적", GamesRadar "idle 장르 르네상스". 비판: 비좁음("claustrophobic"), 튜토리얼 없음, 확대/축소 불편 |
| 터치 적합성 | PC 오버레이 전제. 클릭 부하가 극히 낮아 탭으로 그대로 옮길 수 있음 (모바일판 여부 미확인) |
| 동물원 대입 | **사육사 봇 = 손을 산다.** 초반은 내가 먹이를 주고, 사육사를 고용하면 그 우리는 자동. 대신 "직접 주면 2배" 같은 손 프리미엄 유지 |

## 3. 종합

### (a) 코지 게임이 공유하는 손동작 6가지

| 동작 | 왜 만족스러운가 | 대표 |
|---|---|---|
| **쓸어담기 수확**(드래그 범위) | 한 동작에 여러 결과, 범위가 성장 축(구리 3칸 → 이리듐 18칸) | Stardew 도구, Farm Together, Hay Day |
| **한 방 파괴 + 드롭** | 입력 즉시 파편·아이템 튐, 자동 흡수. "+10%보다 폭발하는 곡괭이" | Forager, AC 바위 |
| **빨아들이기/던지기** | 조준 → 명중 → 반응(2배 플로트) 3박자 | Slime Rancher |
| **배치/회전/이동** | 되돌리기 무료, 창의적 표현, 기능 있는 장식 | AC, Littlewood, Farmside, Rusty's |
| **먹이/쓰다듬기/선물** | 비거래적 돌봄(Lost Garden "gifting & nurturing"), 즉시 하트 | Spiritfarer 포옹, Stardew 동물, Slime |
| **타이머 탭**(부화·수거) | 기다림의 결실을 손으로 확인 | Zen Koi 알, Rusty's 톱니 5회 |

낚시 미니게임은 Stardew·AC·Cozy Grove에 공통이지만 세로폰 한 손 조작에는 부담(추정)이라 우선순위 낮음.

### (b) 손 vs 대기 균형 장치

| 장치 | 구조 | 비고 |
|---|---|---|
| 에너지 상한 | Stardew 270, 도구당 2 | Sun Haven이 "스태미나 없음"을 파는 걸 보면 피로감 원인 |
| 하루 시계 | Stardew 14분/일, 저장은 취침 시 | "한 번만 더" 유발하나 min-max 불안 |
| 실시간 타이머 | AC, Farm Together, Cozy Grove, Zen Koi | 자리 비움 = 성장. 단 하루치 소진 후 "내일" |
| **자동화 구매** | Rusty's 봇, Forager 로봇, Slime auto-feeder·드론, Ooblets 배정 | 손 → 방치의 다리. 반복이 지겨워질 때 팔면 됨 |
| 손 프리미엄 | Slime 선호 먹이 2배, Rusty's 거대 작물·톱니 | 자동화 뒤에도 손이 남는 이유 |
| 무시 허용 | Rusty's Focus Mode, Hay Day "안 죽음", AC NH 대기시간 제거 | 부재 페널티 0 |

### (c) 세로폰 터치 제약

- **가상 조이스틱은 실패 지점**(Forager 모바일 비판, Stardew 모바일 전투). 캐릭터 조작 대신 **대상 탭 → 자동 이동·자동 도구**(Stardew 모바일)로.
- 드래그 수확과 카메라 팬이 충돌 → 드래그는 "익은 것 위에서 시작"할 때만 수확, 빈 땅에서는 팬(Hay Day식; 추정).
- 세로 화면은 엄지 도달 범위가 하단 1/3 → 손동작 대상(우리)은 화면 중앙, 버튼은 하단. Rusty's의 "비좁음" 비판은 좁은 뷰포트에 밀도 높은 시설을 넣을 때의 경고.
- 한 동작 = 한 탭, 시간 정지 없는 대신 **실패 없음**(Stardew는 메뉴에서 시간 정지로 해결).

### (d) 잡일 함정과 회피법

Lost Garden 「Cozy Games」: 코지함을 깨는 것은 "**의무적 책임·선택 불가능한 돌봄**", "거래적 압력을 만드는 외적 보상", 알림. 활동은 "그 자체로 만족스러워야" 한다.
좋은 게임의 회피법:
1. **유지보수는 자동화가 흡수**: 물주기·청소는 봇/스프링클러가 가져가고 사람 손엔 수확·배치·돌봄만 남긴다(Rusty's, Forager).
2. **부재 페널티 없음**: 작물 안 죽음(Hay Day), 오프라인 성장(Farm Together), 대기시간 제거(AC NH).
3. **선택지 폭**: 안 해도 손해 없는 활동 여러 개(Lost Garden "breadth of optional activities"; Forager "지루할 즈음 새 것").
4. **하루 상한을 강제로 두면 반응이 갈림**: Cozy Grove 실시간 게이트는 "일상 의식"이자 불만 요인. 기본은 무제한, 보너스만 일일.

## 4. 우리 동물원에 대입 (제안)

10초 루프 후보 — **"먹이 던지기 → 동물이 몰려와 드롭 → 쓸어담기 → 배치"**:

| 단계 | 손 | 방치 연결 |
|---|---|---|
| 먹이 | 우리 탭 → 먹이 투척, 동물 몰려옴·하트. 선호 먹이면 **드롭 2배**(Slime) | 사육사 고용 시 자동 급식(효율 1배). 수입 틱은 그대로 |
| 드롭 | 알·털·기념품이 바닥에 쌓임(상한 있음) | 오프라인엔 상한까지만 쌓임 → 돌아올 이유(Farm Together, Slime 수집기) |
| 수거 | 드래그 한 번에 여러 개 흡수(Hay Day/Vacpack) | 수집 시설을 사면 자동 수거 |
| 배치 | 장식·울타리 자유 배치, 되돌리기 무료(Littlewood) | 만족도 배율 → 초당 수입 |
| 번식 | 알 타이머 + 탭 부화, 패턴 도감(Zen Koi) | 타이머는 오프라인에도 진행 |

에너지·낮밤·부재 페널티는 넣지 않는다. 자동화(사육사·수집기)는 **재투자 축**이 되어 기존 idle 경제와 합쳐진다.
