# 유니티 프로젝트 초기 세팅 가이드 (안내)

이 프로젝트의 초기 세팅 결정과 절차는 **Claude Code 스킬 `unity-project-setup`**이 원본이다. 다음 프로젝트에서도 같은 방식으로 세팅하려면 그 스킬을 호출한다(`/unity-project-setup`).

- 스킬 위치: `~/.claude/skills/unity-project-setup/` (SKILL.md 실행 절차, reference.md 배경·상세, templates/, scripts/)
- 스킬 저장소: GitHub `jiwon000512/Claude_UnitySkill` (다른 PC에서는 `~/.claude/skills`에 clone)
- 이 프로젝트가 고른 값: [CLAUDE.md](../CLAUDE.md) 「기술 결정」표
- 데이터 테이블 형식: [데이터-테이블-규칙.md](데이터-테이블-규칙.md)

가이드 내용을 이 저장소에 복제하지 않는다. 세팅 방식이 바뀌면 스킬 저장소를 고친다.
