## 되어 있는 것

- **방향**: 「사업가 웜뱃」 기획서 v0.17. 굴 하나 = 업종 하나. 주인공 웜뱃은 말하지 않는다. 빵집 굴을 먼저 다듬는다. 굴 밖은 굴 속 광장(가게 문은 빵집만).
- **빵집 루프**: 조이스틱 웜뱃이 오븐에서 굽고 → 꺼내 진열대에 채우고 → 계산대 자리에 서서 계산. 빵 해금·업그레이드는 사물 시트, 굴 파기로 넓힘.
- **자유 배치·편집 모드**(설계 18·20): 사물을 좌표로 놓고 옮기고 보관. 카드 탭으로 구입.
- **점원**(설계 21·22): 오븐·계산대마다 1명, 일머리·딴짓(멍·산책·수다·외출)·깨우기 대화, 수다는 일하던 점원도 불러 마주 보고 대사를 주고받음(DialogueTable), 「?」가 뜨면 1초 멈춤, 후보 3명, 월급 협상 타이밍 바, 월급은 숫자만 + 가게 공통 월급날 게이지, 못 내면 해고. 연출 1·2단계(월급날 코인 · 협상 결과 · 팝업 등장 · 해고 확인 창 · 버튼 배지 · 모자람 게이지 · 해고 줄 퇴장).
- **광장**(설계 11): 손님이 계단으로 내려와 장식을 들렀다 빵집으로. 웜뱃은 구멍·문에 닿으면 자동으로 오간다.
- **UI**: 공용 조각 한 벌씩(`.claude/rules/ui.md` 2장). 점원 팝업·후보·협상(시안 C 빵집 흥정)·사물 시트·편집 패널·상단 코인.
- **소리**(설계 23): GameKit `SoundManager`, 곳마다 BGM(빵집 「말랑한 칩튠 가게」, 광장 「등불 광장」), 효과음 21개(월드 16 + UI 5, 표 `SoundTable`).
- **월드 연출**: 굴을 파면 흙덩이가 튀고, 웜뱃이 걸으면 발밑 먼지(공용 `Fx.Burst`). 편집 패널도 공용 등장 · 퇴장(`UiFx`). 고용하면 카메라가 굴에서 나오는 점원을 2배로 당겨 비춘다(조작하면 바로 복귀).
- **웜뱃 비켜 가기**: 걷는 손님·점원은 웜뱃 둘레 0.8을 피해 돌아가고, 웜뱃이 설 자리에 있으면 옆에서 기다린다(드나드는 곳·막힌 길은 1.5초 뒤 지나감).
- **테스트**: EditMode 186개. 구조는 사건 버스(설계 16)·곳과 사물(설계 13).
