  - **구현 시작 전 `editor_status`의 `playMode`를 확인한다.** 플레이 중이면 씬 저장·`OpenScene`이 실패한다(03에서 겪음). 사용자가 켠 플레이 모드면 끄기를 기다린다.

## 알려진 문제

- **빌드 타깃이 Standalone이다.** 기술 결정은 Android IL2CPP ARM64인데 아직 안 바꿨다. 제품명·회사명·패키지 ID도 임시(DefaultCompany).
- 폰트가 가변 폰트라 기본 굵기가 얇다. 텍스트는 전부 Bold.
- 씬의 `Global Light 2D`는 원근 카메라에서도 스프라이트를 비추지만, 2D 라이트가 필요 없어지면 URP 2D Renderer → Universal Renderer 전환을 검토한다.
- 시설은 1단계에만 월드에 나타나고 단계가 올라도 모습이 안 바뀐다. 실제 아트가 오면 단계별 스프라이트(`sprite` 배열, version +1)를 검토.
