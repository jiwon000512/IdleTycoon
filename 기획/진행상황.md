## 도구 함정 (Unity CLI)

- 구현·에셋 작업 전 `editor_status`의 `playMode` 확인. 플레이 중이면 씬 저장·프리팹 교체가 틀어진다. `run_tests`는 반드시 `editor_stop` 후 `playMode=stopped`에서 `--mode EditMode --timeout 150`으로 **한 번만** 호출(같은 명령을 파이프로 두 번 부르면 두 번째가 겹쳐 테스트 러너가 깨지고 파이프라인이 막힌다. 2026-09-18). 막히면 `taskkill //F //PID`로 에디터를 죽이고 **`ProjectTycoon/Temp/UnityLockfile`을 지운 뒤** `unity projects open`(잠금 파일이 남으면 모달이 떠 영원히 연결되지 않는다).
- 에디터 창이 뒤에 있으면 플레이 프레임이 멈춘다 → `editor_focus`. JSON·에셋을 고친 뒤엔 `AssetDatabase.ImportAsset(path, ForceUpdate)`로 강제 임포트한 뒤 플레이.
- 같은 경로에 에셋을 다시 만들 때는 `DeleteAsset` → `CreateAsset` → 프리팹 `ImportAsset(ForceUpdate)` → `recompile` 뒤 플레이(옛 객체가 "이름 없는 Tile"로 남는다).
- 여러 줄 C#은 `run_script --file --entry --mode ephemeral`. 일회성 조립·조회 스크립트만 scratchpad, 프리팹을 통째로 만드는 스크립트는 `Scripts/Editor`에 MenuItem으로. `GetComponent ?? AddComponent`는 가짜 null로 실패 → `TryGetComponent`.
- 플레이 중 상태는 `GameManager.Instance.State/...`를 `run_script`로 읽는다. 1초짜리 연출은 캡처 대신 상태 조회. 정확한 화면 좌표는 `capture_game_view --source camera --width 1080 --height 1920`.
- 콘솔의 `TreeViewController NullReference`·`GUIClips`는 Hierarchy 창의 에디터 내부 오류. 게임 오류 판정은 `error CS`·게임 스택만.
- Git Bash는 `export MSYS_NO_PATHCONV=1`. 에디터 열기 `unity projects open ProjectTycoon`, 연결 확인 `unity pipeline list`.
