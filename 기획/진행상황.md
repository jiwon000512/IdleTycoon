# 진행 상황

CLAUDE.md가 매 세션 불러온다. 한 항목 200자 안, 끝난 기능의 구현 세부는 적지 않는다(코드·`포트폴리오.md` 4장·git에 있다). 갱신 2026-09-29.

## 되어 있는 것

- **방향**: 「사업가 웜뱃」 기획서 v0.22. 굴 하나 = 업종 하나. 주인공 웜뱃은 말하지 않는다. 빵집 굴을 먼저 다듬는다. 굴 밖은 굴 속 광장(가게 문은 빵집만).
- **빵집 루프**: 조이스틱 웜뱃이 오븐에서 굽고 → 꺼내 진열대에 채우고 → 계산대 자리에 서서 계산. 빵 해금·업그레이드는 사물 시트, 굴 파기로 넓힘.
- **자유 배치·편집 모드**(설계 18·20): 사물을 좌표로 놓고 옮기고 보관. 카드 탭으로 구입.
- **점원**(설계 21·22): 오븐·계산대마다 1명, 일머리·딴짓(멍·산책·수다·외출)·깨우기 대화, 수다는 일하던 점원도 불러 대사를 주고받음, 「?」가 뜨면 1초 멈춤, 후보 3명, 월급 협상 타이밍 바, 월급은 숫자만 + 가게 공통 월급날 게이지, 못 내면 해고. 연출 1·2단계.
- **광장**(설계 11): 손님이 계단으로 내려와 장식을 들렀다 빵집으로. 웜뱃은 구멍·문에 닿으면 자동으로 오간다.
- **UI**: 공용 조각 한 벌씩(`.claude/rules/ui.md` 2장). 점원 팝업·후보·협상(시안 C 빵집 흥정)·사물 시트·편집 패널·상단 코인.
- **소리**(설계 23): GameKit `SoundManager`, 곳마다 BGM(빵집 「말랑한 칩튠 가게」, 광장 「등불 광장」), 효과음 21개(월드 16 + UI 5, 표 `SoundTable`).
- **월드 연출**: 굴 파기 흙덩이 · 걸음 먼지(`Fx.Burst`), 편집 패널 등장 · 퇴장(`UiFx`), 고용하면 굴에서 나오는 점원을 2배로 당겨 비춘다.
- **웜뱃 비켜 가기**: 걷는 손님·점원은 웜뱃 둘레 0.8을 피해 돌아가거나 비킬 때까지 기다린다.
- **빵집 소품**(09-29): 오븐 1·2단 · 진열대 · 계산대 · 식빵은 C 「웜뱃 굴 공방」(강돌 · 흙 · 뿌리, `Shop/Source~/make_shop_props.py`). 모든 리소스는 앞쪽 위에서 내려다본 평행 투영(`art.md` 시점).
- **캐릭터 애니메이션**(09-29): 웜뱃 · 점원 · 손님 넷 모두 정지 그림 한 장을 부위로 조립(`Shop/Source~/make_anim.py`). 걷기 8 · 몸 전체 숨쉬기 4 · 깜빡임, 서 있으면 가끔 종마다 다른 딴짓.
- **웜뱃 똥**(설계 24): 걸으면 가끔 네모 똥. 손님은 피해 가고 길이 없으면 🤢 포기, 버튼으로 치우기. 그림·소리 더미.
- **테스트**: EditMode 203개. 구조는 사건 버스(설계 16)·곳과 사물(설계 13).

4. 햅틱(협상 탭 · 고용 · 해고 · 굴 파기): Android 빌드 타깃으로 바꾼 뒤.

- `Assets/_Recovery/`의 미추적 씬(0 (1) · 0 (2))은 지워도 된다.
- 웜뱃 외곽선은 (36,24,24)로 `art.md`의 (52,32,32)과 다르다. 검사는 캐릭터별 팔레트로.
