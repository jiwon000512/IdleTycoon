# 진행 상황

CLAUDE.md가 매 세션 불러온다. 한 항목 200자 안, 끝난 기능의 구현 세부는 적지 않는다(코드·`포트폴리오.md` 4장·git에 있다). 갱신 2026-09-30.

## 되어 있는 것

- **방향**: 기획서 v0.30. 주인공 웜뱃은 말하지 않는다. 빵집 굴을 먼저 다듬는다. 굴 밖은 굴 속 광장(빵집 문 · 농장 문). 같은 업종의 굴이 여럿일 수 있다.
- **빵집 루프**: 웜뱃이 굽고 → 진열대에 채우고 → 계산대에 서서 계산. 빵 해금·업그레이드는 사물 시트, 굴 파기로 넓힘.
- **자유 배치·편집 모드**(설계 18·20): 사물을 좌표로 놓고 옮기고 보관. 카드 탭으로 구입.
- **점원**(설계 21·22): 오븐·계산대마다 1명, 일머리·딴짓(멍·산책·수다·외출)·깨우기, 후보 3명, 월급 협상 타이밍 바, 가게 공통 월급날 게이지, 못 내면 해고. 연출 1·2단계.
- **광장**(설계 11): 손님이 계단으로 내려와 장식을 들렀다 빵집으로. 웜뱃은 구멍·문에 닿으면 자동으로 오간다.
- **농장 칸 밭**(설계 25·27): 광장 계단 오른쪽 문 → 농장 굴. 빵집처럼 파고(층 4×4), 판 칸에 서서 갈기(50) → 밭, 심기 버튼, 익으면 밟고 지나며 거둬 창고로. 빵마다 레시피(밀 2·3·4), 모자라면 칩 잠김 · 점원 「…」. 밭은 칸 안쪽 몸통(테두리 · 고랑 셋)이라 몸통을 밟아야 거둔다.
- **거름 · 덤**(설계 28): 빵집 똥을 치우면 거름, 심을 때 자동 1개(자람 −40% · 덤 ×2). 거둘 때 20%로 반짝돌(석상용).
- **UI**: 공용 조각 한 벌씩(`.claude/rules/ui.md` 2장). 점원 팝업·후보·협상(시안 C 빵집 흥정)·사물 시트·편집 패널·상단 코인·창고(설계 26, 칸 격자 → 획득처·사용처).
- **소리**(설계 23): GameKit `SoundManager`, 곳마다 BGM(빵집 · 광장 · 농장), 효과음 27개(월드 22 + UI 5). 곳에 매인 소리는 웜뱃이 있는 곳의 것만.
- **월드 연출**: 파기 흙덩이 · 걸음 먼지 · 발소리 · 거두기 낟알, 편집 패널 등장 · 퇴장, 고용 줌인.
- **웜뱃 비켜 가기**: 걷는 손님·점원은 웜뱃 둘레 0.8을 피해 돌아가거나 비킬 때까지 기다린다.
- **빵집 소품**: 오븐·진열대·계산대·식빵은 C 「웜뱃 굴 공방」(`make_shop_props.py`).
- **캐릭터 애니메이션**: 모두 정지 그림 한 장을 부위로 조립(`make_anim.py`). 걷기 8 · 숨쉬기 4 · 깜빡임 · 종마다 딴짓.
- **웜뱃 똥**(설계 24): 걸으면 가끔 네모 똥. 손님은 피해 가고 길이 없으면 🤢 포기, 버튼으로 치우기.
- **테스트**: EditMode 229개. 구조는 사건 버스(설계 16)·곳과 사물(설계 13).
