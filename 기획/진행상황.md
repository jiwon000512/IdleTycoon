# 진행 상황

CLAUDE.md가 매 세션 불러온다. 한 항목 200자 안, 끝난 기능의 구현 세부는 적지 않는다(코드·`포트폴리오.md` 4장·git에 있다). 갱신 2026-09-28.

## 되어 있는 것

- **방향**: 「사업가 웜뱃」 기획서 v0.12. 굴 하나 = 업종 하나. 빵집 굴을 먼저 다듬는다. 굴 밖은 굴 속 광장(가게 문은 빵집만).
- **빵집 루프**: 조이스틱 웜뱃이 오븐에서 굽고 → 꺼내 진열대에 채우고 → 계산대 자리에 서서 계산. 빵 해금·업그레이드는 사물 시트, 굴 파기로 넓힘.
- **자유 배치·편집 모드**(설계 18·20): 사물을 좌표로 놓고 옮기고 보관. 카드 탭으로 구입.
- **점원**(설계 21·22): 오븐·계산대마다 1명, 일머리·딴짓(멍·산책·수다·외출)·깨우기 대화, 후보 3명, 월급 협상 타이밍 바, 월급 못 내면 해고.
- **광장**(설계 11): 손님이 계단으로 내려와 장식을 들렀다 빵집으로. 웜뱃은 구멍·문에 닿으면 자동으로 오간다.
- **UI**: 공용 조각 한 벌씩(`.claude/rules/ui.md` 2장). 점원 팝업·후보·협상(시안 C 빵집 흥정)·사물 시트·편집 패널·상단 코인.
- **소리**(설계 23): GameKit `SoundManager`, 곳마다 BGM(빵집 「말랑한 칩튠 가게」, 광장 「등불 광장」), 효과음 20개(월드 15 + UI 5, 표 `SoundTable`).
- **테스트**: EditMode 175개. 구조는 사건 버스(설계 16)·곳과 사물(설계 13).
