# UI 디자인 규칙

버전 v1.1 · 2026-09-23. 원본(근거·미리보기·결정 경위)은 아티팩트 https://claude.ai/artifact/B3sRpN8QNks8zj4Pkc65vh . 여기에는 구현이 참조하는 숫자표만 둔다. 결정: F1 갈무리 픽셀 폰트 · F2 1 UI px = 화면 4px · F3 시트 뒤 딤 45% + 상단 바 20 UI px · F4 강조색 주황(2026-09-23 사용자 확정). v1.1: 상단 HUD 시안 C — 초록 바 삭제, 반투명 캡슐에 금색 코인 숫자, 가게 이름 줄 삭제(사용자 선택).

## 1. 단위

| 항목 | 값 |
|---|---|
| 기준 해상도 | 1080×1920 (CanvasScaler Scale With Screen Size, Match 0.5, GameKit UIManager 기본) |
| UI 픽셀 | 1 UI px = 화면 4 px → 캔버스 270×480 UI px. 월드 한 칸(2px·PPU 80)과 같은 크기 |
| UI 스프라이트 임포트 | PPU 25, Point, 압축 없음, Sliced는 Full Rect. 9-slice 코너 6 UI px |
| 정수 규칙 | 크기·간격·글자는 UI px 정수. 반 픽셀·회전 없음, 확대는 정수 배 |

## 5. 모션 (코드 상수)

시트 열기 0.15s ease-out(아래→위), 닫기 0.10s. 눌림 즉시 1px↓. 구매 성공 = 행 크림→흰 0.15s + 사물 스케일 1.05 1회. 부족 = 비용 글자 1px 좌우 0.2s. UI에 흔들림·입자·줌 없음.

## 6. 제작

- 부품 원본은 Codex 시안(시트 목업·버튼·아이콘 3장씩 → 선택 → 그 결을 참조로 부품별 생성) → `make_pixel.py`로 격자 강제 → `Sprites/UI/Source~/make_ui.py`가 9-slice 조각·상태별 PNG로 자르고 팔레트를 2장 표로 맞춘다. 규칙과 어긋나는 칸은 스크립트가 보정.
- 아이콘은 시안에서 자르고, 빵 아이콘은 기존 스프라이트 재사용.
- 폰트 에셋은 갈무리 TTF → TMP 비트맵(에디터 스크립트). 프리팹은 `ZooTycoon/Bake/UI`(UIBaker)가 이 표의 숫자로 조립. 손으로 만든 프리팹 없음.
- 월드 태그는 UI가 아니라 월드 스프라이트로 굽는다.
