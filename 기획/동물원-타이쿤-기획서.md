## 1. 개요

- 1인 개발 모바일 게임. AI(이미지 생성·코딩 보조)를 활용해 만들고 출시해 수익화한다.
- 장르: **방치형 경영 타이쿤**. 방치형 요소를 타이쿤보다 강하게, 캐주얼하게. 지속형(리셋 없음).
- 한 줄: 화면 중앙 아래의 큰 가차 버튼으로 동물을 뽑아 우리에 놓고, 관광객 수입(초당)으로 다시 뽑거나 홍보에 투자한다.
- 개발 순서: 메인 루프를 먼저 만들고, 루프가 재미있다고 확인된 뒤 컨텐츠를 붙인다.
- 아트: 귀여운 SD 2D. ChatGPT 이미지 생성 → 배경 제거 → 스프라이트 애니메이션.

## 3. 핵심 루프

재화는 코인 하나, 소비처는 뽑기와 홍보 둘, 성장 축은 동물 수·레벨·홍보 셋.

1. **가차 버튼** — 코인을 내고 등급 가중치 확률로 동물 1마리를 뽑는다.
2. 결과가 **새 종**이면 빈 우리에 자동 배치(빈 우리가 없으면 대기실). **중복**이면 그 동물 레벨업(레벨당 수입 +50%).
3. 배치된 동물들의 **초당 수입** 합계 × **홍보 배수** = 코인이 쌓인다.
4. 코인은 **다시 뽑기**(루프의 본체) 또는 **홍보 업그레이드**(배수 ↑)에 쓴다.
5. **누적 획득 코인**이 동물원 레벨을 올리고, 레벨이 잠긴 우리와 홍보를 해금한다. 도감은 발견·레벨을 기록한다.
6. 앱을 닫아둔 동안은 초당 수입 × 경과 시간(캡)을 복귀 시 **오프라인 수익**으로 지급한다.

"지금 뽑을까, 홍보에 넣을까"가 이 게임의 유일한 결정이므로, 두 소비처의 효율이 번갈아 앞서도록 숫자를 잡는 것이 튜닝의 핵심이다.

## 4. 화면 구성

세로 고정, 한 화면, 카메라 이동 없음, 기준 해상도 1080×1920.

| 영역 | 내용 |
|---|---|
| 상단 바 | 코인(K/M/B 표기) · 초당 수입(`초당 n`) · 동물원 레벨(`Lv.n`)과 진행도(`누적/다음 기준`, 마지막 레벨이면 `MAX`) |
| 우리 격자 3×3 | 열린 우리(동물 SD 스프라이트 + 이름 + Lv + 초당 수입) / 빈 우리 / 잠긴 우리(해금 레벨 표시). 우리를 탭하면 동물 정보. 대기실 동물은 배지로 표시 |
| 관광객 띠 | 관광객 실루엣이 오가는 연출. 홍보 레벨에 따라 수만 늘어난다 |
| 탭 2개 | 홍보(현재 단계·다음 비용) · 도감(발견 n/8). 각각 팝업 하나 |
| 큰 가차 버튼 | 화면 중앙 아래. 비용과 확률 상시 표시. 누르면 뽑기 연출 → 새 종 또는 레벨업. 코인 부족 시 비활성 + 남은 시간 |
| 오프라인 팝업 | 복귀 시 화면 위에 수익 지급 팝업(광고 2배 자리는 비워 둠) |

첫 버전에서 플레이어가 누르는 것은 큰 버튼, 홍보 버튼, 우리(정보 보기) 세 가지뿐이다. 격자 9칸에 8종을 담고 한 칸이 남으므로 종을 늘릴 때 격자를 키운다.

## 6. 데이터와 숫자 초안 (전부 시작값, 프로토타입에서 튜닝)

### 6.1 동물 8종 (animals.json)

| ID | 이름 | 등급 | 기본 초당 수입 | 뽑기 확률 |
|---|---|---|---:|---:|
| a01 | 토끼 | 일반 | 1.0 | 17.5% |
| a02 | 염소 | 일반 | 1.0 | 17.5% |
| a03 | 거북이 | 일반 | 1.0 | 17.5% |
| a04 | 오리 | 일반 | 1.0 | 17.5% |
| a05 | 여우 | 희귀 | 5.0 | 9.0% |
| a06 | 펭귄 | 희귀 | 5.0 | 9.0% |
| a07 | 사슴 | 희귀 | 5.0 | 9.0% |
| a08 | 사자 | 전설 | 30.0 | 3.0% |

등급 확률 일반 70% / 희귀 27% / 전설 3%. 뽑기 1회의 기대 수입 증가 ≈ 2.95/초(0.7×1 + 0.27×5 + 0.03×30). 색깔 변형은 첫 버전에 없지만 데이터에 `variantId` 칸을 미리 둔다.

### 6.2 레벨과 수입

- 레벨: 중복 1마리당 +1, 상한 없음
- 초당 수입 = 기본 × (1 + 0.5 × (레벨 − 1)). Lv.10 = 5.5배, Lv.20 = 10.5배
- 총 수입 = Σ(배치된 동물 수입) × 홍보 배수. 대기실 동물은 0
- 대기실: 새 종인데 빈 우리가 없으면 대기. 우리가 열리면 자동 입장

### 6.3 가차 비용과 버튼 리듬

비용 = 100 × 1.12^n (n = 누적 뽑기 횟수)

| 누적 뽑기 n | 비용 | 기대 초당 수입(대략) | 다음 뽑기까지 | 느낌 |
|---:|---:|---:|---:|---|
| 0 | 100 | 시작 코인 300 | 즉시 ×3 | 첫 30초에 동물 셋 |
| 5 | 176 | ≈ 9 | ≈ 20초 | 연타 구간 |
| 10 | 311 | ≈ 18 | ≈ 17초 | 홍보 1단계 열림 |
| 20 | 965 | ≈ 35 | ≈ 28초 | 세션 안에서 여전히 여러 번 |
| 40 | 9,300 | ≈ 70 (× 홍보) | ≈ 2분 | 방치 구간 — 오프라인 수익이 주 수입 |

목표 리듬: 초반 세션 5분 동안 10회 안팎, 이후 접속당 2~4회. 지수 1.12는 시작값이며 홍보 배수와 동물원 레벨 해금이 곡선을 눌러주므로 셋을 같이 본다.

### 6.4 홍보 · 동물원 레벨 · 오프라인 · 시작 상태

- 홍보: 10단계. 단계당 전체 수입 배수 +10%(Lv.10 = ×2.0). 비용 500 × 1.8^k. 동물원 Lv.3에 해금. 단계마다 관광객 연출 +1
- 동물원 레벨(누적 획득 코인): Lv.1 0(우리 3) · Lv.2 2,000(우리 4) · Lv.3 8,000(우리 5, 홍보 해금) · Lv.4 25,000(우리 6) · Lv.5 70,000(우리 7) · Lv.6 200,000(우리 8) · Lv.7 500,000(우리 9, 예비)
- 오프라인: 복귀 시 초당 수입 × 경과 초, 최대 8시간. 팝업 지급
- 시작 상태: 코인 300, 우리 3, 동물 0, 홍보 잠김. 첫 뽑기 3회로 우리를 채우는 것이 튜토리얼을 대신한다

## 7. 한 세션의 흐름 ("하루 몇 번 들여다보기", 1~3분)

1. 앱을 연다 → 오프라인 수익 팝업을 받는다.
2. 큰 버튼을 누를 수 있는 만큼 누른다. 새 종이면 우리가 채워지는 연출, 중복이면 레벨업 연출.
3. 홍보 단계를 올릴 수 있으면 올린다. 관광객이 한 명 늘어난다.
4. 동물원 레벨이 올랐으면 잠긴 우리가 열리고 대기실 동물이 들어간다.
5. 도감을 한 번 열어보고 나간다. 복귀 동기는 "코인이 얼마나 쌓였을까"와 "아직 못 본 종".

첫 버전에서 확인할 질문은 하나: 2단계의 버튼 누르는 순간이 30번째에도 기다려지는가. 아니라면 확률·연출·비용 곡선을 바꾸고, 그래도 아니라면 배치나 고유 효과 같은 두 번째 동사를 앞당긴다.

## 8. 구현 메모 (제안)

- 데이터: JSON 테이블 5개(`Assets/Resources/Data/`) — animals(id, 이름, 등급, 기본 수입, variantId 예비), grades(등급, 확률 가중치, 색), zoo_levels(레벨, 누적 코인 기준, 해금 우리 수, 홍보 해금), game_config(홍보·가차 비용 수식 상수, 시작 상태, 오프라인 캡), strings(UI 문구). JSON이 유일한 원본이고 Newtonsoft.Json으로 로드, 스프라이트는 `sprite` 경로 칼럼으로 참조, EditMode 테스트로 검증. ScriptableObject는 쓰지 않는다(v0.5). 형식은 `데이터-테이블-규칙.md`
- 세이브: JSON 1파일 — 코인, 누적 코인, 뽑기 횟수, 홍보 단계, 동물별 레벨, 대기실 목록, 마지막 저장 시각(UTC). 복귀 시 (now − lastSaved)를 8시간으로 잘라 초당 수입을 곱함. 기기 시간 조작은 첫 버전에서 방어하지 않음
- 숫자: double + K/M/B 표기 함수. 수입 갱신은 0.1~0.25초 틱, 화면 숫자만 보간
- 확률: 가중치 테이블에서 난수 1회. 결과 연출은 "새 종"/"레벨업" 프리팹 2개로 시작
- 아트 파이프라인: 이미지 생성 → 배경 제거 → 2~4프레임 대기 시트 → SpriteAtlas 1개

## 9. 루프 다음에 붙일 것 (우선순위)

1. 리워드 광고 — 오프라인 수익 2배, 무료 뽑기 1회, 수입 부스트 (첫 수익원)

4. 고유 효과 + 직접 배치 — 전설·희귀에 인접 보너스·세트 효과, 우리 간 이동
5. 튜토리얼·사운드·BGM
6. 미션·업적, IAP(광고 제거·스킨)
